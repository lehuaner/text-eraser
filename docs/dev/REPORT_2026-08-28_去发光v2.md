## 二、最终算法形态

### v2 去发光管线（当前唯一算法）

```
原图
 ├─ 发光区检测（zone）: 强绿种子(g-max>8 且 g>95) + 八连通生长
 │    "绿色 或 比背景亮" 自适覆盖, 外扩 deglow_range(默认10px)
 ├─ 文字蒙版: detect_text_mask(原图,tint=False) ∪ (去发光图,tint=True) → 闭运算
 │    + 方案A: 小字框(高<56px)放大2~3x分割并集(只增不减, 细笔画不丢)
 │    + 方案B: 亮侧连通补全 _fill_bright_near_mask(吃 AA 渐隐环带)
 ├─ 保护圈 protect_px(默认1px): 文字笔画+外扩, 圈内只减绿铸、不做羽化
 ├─ 去发光:
 │    文字本体(保护圈内) → 减绿度(g−max(R,B)→0), 保留本文
 │    光晕区(zone∖保护圈) → 背景重建:
 │       B = 测地最近源色场(多源Dijkstra, 边权=1+3·|Δlum|, 跨色块不串色,
 │             待重建区内收3px露同色源后计算, INTER_CUBIC上采样+σ4平滑)
 │       detail = (原图 − σ2高斯) × 近字衰减(0~8px 线性抬升)
 │       rebuilt = B + detail
 │    可选: 色度结构保留(开关) → 非光晕弱色结构(|R−B|>8 且 g-max<20) 从原图回贴
 └─ 去字: 在 clean 上走标准非高亮算法
        detect_text_mask(tint_fill=True, fill_white) → 膨胀 → patch_fill
```

### 前端形态（index.html / app.js）

- 「开启去发光」开关（勾选=走 v2，取消=普通去字，无下拉）
- 参数：去发光强度(0~1)、文字保护圈(0~8px, 默认1)、去发光范围外扩(px)、蒙版透明度扩展(px)、色度结构保留(checkbox, 默认关)
- 复选框统一为「勾选框在左、文字在右」行内布局；CSS/JS 带 `?v=4` 缓存版本号

## 三、关键决策链（含讨论结论）

| 问题 | 讨论过的方向 | 最终决策 | 理由 |
|---|---|---|---|
| 蒙版未覆盖白字细部 | 膨胀mask(A)/换用去文字算法(B) | 先确认B已生效 → 上采样分割并集 + 亮侧补全 | 低分辨率细笔画 Otsu 切碎、CC 门限误删，膨胀无种子可长；并集只增不减 |
| 去发光区与外部背景有色差(556) | 均色/像素alpha反解/低频延拓+细节 | 方案B：背景低频色场延拓 + σ2高通细节 | 物理上光晕是低频现象；不引入"均色"、保留纹理 |
| 668 浅色块被补成深色 | zone收缩(弊端多)/测地最近源 | 测地最近源 + 待重建区内收3px | 不牺牲光晕全覆盖、不加新 magic number、通用 |
| 浅色块整体被 zone 吞没 | 内收3px 露同色源 | 内收3px | 无同色源时任何插值数学上无解，露源让测地可以绕行取色 |
| 文字边缘一圈绿 / 补色 | 保护圈 4px 原样 / 1px 减绿 | 保护圈 1px 可调，圈内减绿铸 | 用户要求"文字本来什么样就什么样"(圈内留本色AA)，同时用 detail 近字衰减防绿 |
| 黄条被重建抹掉 | 处理/不处理 | 新增「色度结构保留」开关(默认关) | 弱色结构(R−B 明显但绿度非光晕)应按需保留 |
| 保护圈宽度 | 固定值/可调 | 默认1px + 前端0~8可调 | 通用性与可控性兼顾 |

## 六、已知限制与后续可选

1. **测地重建是"最快到达的同色背景"而非物理去光晕**：极端场景（色块几乎整体被吞且无任何同色源露出）仍可能串色，正解仍是像素级 alpha 反解（方案A）。
2. 过渡带 1~2px 阶梯感：源映射上采样的固有现象，可调 B 平滑 σ 或边权 λ，边际收益递减。
3. 色度结构保留目前是"是否-强度0.85"二值+blur 软边；如需按结构强度连续保留可再细化。
4. 历史诊断脚本（`diag_v2*.py` 等）仍为 untracked，未纳入提交。
