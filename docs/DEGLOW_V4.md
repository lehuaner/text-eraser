## 2. 与规格的工程偏差（可执行性取舍，均写入代码注释）

- **D1 · B̂_ring 求解**：规格为「1/4 网格 Laplace 稀疏解 + 双三次上采样」；本实现用
  「guided 全局场 + 域内锚定 offset（环带暗侧截尾均值）」，offset 使 B̂_ring 域内均值
  = 环带实测背景。精度损失由 M-G 校验门兜底；scipy 已可用，Laplace 版列为后续替换点。
- **D2 · 环带暗侧截尾**：规格按 5%~95% 截尾（环带无污染假设）；本项目环带常落在
  光晕尾迹内（亮绿残迹），实测必须取 **≤40% 亮度分位**的暗侧均值才不被拉偏——
  与已验证零残留的通道法「暗背景分位数」同策略（项目记忆）。
- **D3 · 色晕生长轮（补偿欠覆盖）**：引导滤波会把大而平滑的光晕当背景 → D 偏小 →
  规格的第 1/2 轮在真实 halo 上欠生长（实测 2991px vs 全域亮绿 11701px）。落地补
  `grow_veil`：任意色 veil 连通生长（色度≥20、相对全局暗背景的色向余弦>0.6、亮度≥背景），
  对标通道法 zone；单域 ≤25%、全图并集 >25% 即安全阀回退到第 2 轮结果。
- **D4 · 档3 重建**：规格以 PatchMatch 为主（S≥1.5）+ SYNTH 回退；实测 PatchMatch 会把
  环带残留发光当取样源复制进光晕区（泛绿），故档3 一律「环带常数背景色」落底
  （等于规格 SYNTH 的 B̂_ring 底分支），仅无环带信息小块才走 PatchMatch。
- **D5 · 强发光守卫**：规格无显式守卫；对齐通道法 min_strong 语义加「强彩色信号
  (chroma>45 且 max>90) 占比 ≥35% + 域均值 ≥15 + 方向一致 ≥0.5」门，普通图/灰阶纹理零改动。
- **D6 · α 无标度域**：additive/screen/unknown 无 G 标度 → α 仅作路由代理（p95 归一），
  反演不依赖 α（投影法），与规格「档2 低频精确」一致。
- **D7 · σ̄_tex 平滑图下限**：平坦照片 σ̄≈1，校验容差取 `kv·local·max(σ_tex, 4)` 防误杀。
- **D8 · veil 兜底顺序（GT 集暴露后修复）**：规格/初版把守卫提前返回放在色晕轮之前——
  平滑光晕被引导滤波吸收（|D| 小）→ 首轮欠覆盖 → 守卫拒绝 → **色晕轮永不触发**。
  现改为：首轮+守卫判空时先跑 `_veil_fallback`（色晕轮 + 域均色度≥fallback_chroma +
  方向一致性≥fallback_align + 最小面积 + 25% 阀），仍空才判无发光。合成中量光晕
  （A≈0.6）从 has_glow=False 修复为检出（ε 0.37→0.08）；「纯文字无发光」保持零改动
  （实测纯文字域均色度≈4 vs 光晕≈20+，fallback_chroma=12 有效区分）。
- **D9 · 档3 落底色来源（glow.png 泛绿根因，2026-08-27 修复）**：主域 100% 路由档3 时，
  `ring_fill`（环带暗侧 40% 截尾均值）在「平滑大光晕把环带淹没」的场景取到**光晕色**
  （实测 [72,75,58] 橄榄刷绿 17045px）。修复：落底色改由 `rebuild._real_bg_color`
  从**域外 prov==ORIGINAL 真背景**取样；且不再用暗侧截尾——实测该图暗侧 40% 恰是
  偏绿暗尾迹 [74.8,75.1,60.5]（环带均值 [94,91,77] 才是真背景），改用**亮度中位窗
  35%~75% + 剔 chroma>60**（得到 [98,94,81] R>G>B 暖向，与真实背景同一色相）。
  取不到 → 回退全局中性暗背景；仍失败 → 沿用 ring_fill。擦除全流程 olive 残留
  25067→2175（91%↓），green 0，纯文字零改动守卫不变。
- **D10 · 残绿判据扩展（D9 配套）**：`residual_cleanup` 原判据只管纯绿
  （g−max(r,b)>6），去发光残留常被拉进「亮但不绿」橄榄区间 → 全漏。新增橄榄判据：
  `g≈r>b（蓝通道显著低）+ 与全局背景差>18 + 偏移方向与域 u_hat 一致（防误删
  真实同向物体）+ 域邻域内`；`max_touch` 3000→6000。D9 后落底色为暖向，
  不再命中 olive 判据 → 清理只对真绿尾迹生效，无二次覆盖。`

## 4. 接入方式

- **后端**：`app/main.py::erase` 新增 Form 字段 `deglow_scheme`(channel/v4/off)，
  透传 `core/eraser.py::erase_text(..., deglow_scheme=...)`；
  方案映射：`off`→发光关闭（等价 glow_mode=off）；`v4`→`_erase_v4_deglow`
  （先去发光→原样走普通去文字路径，严格遵循项目约束）；`channel`→现有行为。
- **返回**：`deglow_b64`（去发光后全图，复用前端面板）+ `dglow_report`（每域结构化报告）。
- **前端**：高级参数新增「去发光方案」下拉（通道法/v4/off），`app.js` 随表单提交。

## 6.1 工程标定层现状（本轮新增，规格 §5/§6/§7/§8）

- **GT 全集 2278 例**（size=512；基础网格 1728 + 孤立域 72 + 饱和 24 + 源稀缺 48 +
  灰度轴 6 + 重点交叉各 200），`gt_hash` 参与 frozen.json 断言（生成器任何轴改动即漂移）。
- **分层指标已跑通**：基线回归 16 例全阻断——FILLED 层 dE94≈8.9/rmse≈17（门 6/—），
  ε_all≈24%。**模式判别 100% 正确**（本切片），瓶颈纯在移除/重建质量。
- **R6 触发证据**：k_v∈{1.5,2,2.5,3,4} 下 ε 全≈22%（重建面积率≈15.5%）——
  说明主导项是「域覆盖 + 移除质量」，而非校验阈值 k_v；收紧 k_v 无济于事，
  需先改进：域覆盖（色晕轮半径/阈值）、FILLED 环带背景色漂移、残差回灌。
- **下一步**（按此推进可使 M6 收敛）：① 扩大色晕轮覆盖（降低 chroma_min / 多轮）；
  ② FILLED 落底色改用「环带暗侧截尾 + 域内中值」去漂移；③ 残差轮对 FILLED 周边
  再做一次 ΔE 门回灌；④ 全量 GT 夜间重标 + frozen.json。
